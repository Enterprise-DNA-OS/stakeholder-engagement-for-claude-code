# Why the free version has no front end

The recurring work is a review: which commitments are due, which issues remain unresolved, who has not been contacted and what evidence belongs in the consultation report. Records and repeatable queries do that work without a hosted editing screen.

A browser interface provides interactive maps, mobile capture, offline synchronisation, drag-and-drop layouts and separate sign-ins. This free version provides none of those. It writes read-only HTML reports and private document drafts. They are local files, not an editing application or public portal. Refresh them after changing records.

Enterprise DNA can build the screens and connections your team needs as part of a customised version. Shared access, data residency and permissions need a reviewed design before deployment. The free CLI assumes a trusted local operator and one embedded database writer at a time.
